# GPT Plus 휴대폰 구형 노트북 하나로 쌀먹하기

ChatGPT Plus + Remote Desktop Commander + Codex + Git/GitHub + Google Drive의 역할을 분리해 휴대폰과 구형 노트북 한 대로 개발·실행·검증하는 구조를 설명하는 공개 GitHub Pages 사이트입니다.

## 제작 고지

본문, 문장 구성, 표, 설명 도표 및 X 게시물용 이미지는 GPT를 활용해 작성·제작했습니다. 실제 환경 구성, 실행, 테스트와 벤치마크 측정값은 해당 환경에서 직접 확인한 결과를 바탕으로 정리했습니다.

이 저장소에는 투자 프로젝트 코드, 데이터, API credentials 또는 기타 비공개 자료를 포함하지 않습니다.
